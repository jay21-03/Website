### Nếu quy về 4 milestone lớn

| Milestone | Phase                  | Kết quả                                                        |
| --------- | ---------------------- | -------------------------------------------------------------- |
| **M1**    | Phase 0 + Phase 1      | Foundation + Auth/Security + Catalog                           |
| **M2**    | Phase 2 + đầu Phase 3  | Cart + Inventory + Order/Payment Core                          |
| **M3**    | cuối Phase 3 + Phase 4 | Checkout + payOS + toàn bộ CG-001..007                         |
| **M4**    | Phase 5 + Phase 6      | Notification + Reporting + Frontend hoàn chỉnh + Test + Deploy |

**Critical path thực tế là:**

`Catalog → Inventory/Cart → Order/Payment Core → CG-001 → payOS → CG-007/Webhook → Full E2E`.

Không nên bắt đầu bằng Payment/payOS trước Inventory và Order, vì `CG-001`, `CG-002`, `CG-003`, `CG-004`, `CG-005` đều phụ thuộc trực tiếp vào các module đó. 

Đây có thể dùng trực tiếp làm bộ khung để bước tiếp theo **chia từng Phase thành task nhỏ rồi phân cho 4 thành viên**.
